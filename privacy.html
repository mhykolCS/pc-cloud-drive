PC Cloud Drive

Privacy policy

Effective 2 October 2026. PC Cloud Drive is a personal configuration of rclone used by its owner to access and manage files in their own cloud accounts.

Data accessed and purpose

The application accesses Google Drive file contents, names, folder structure, modification times, checksums, and storage information to browse files, provide a local filesystem mount, and upload or download files at the owner's direction. It also reads the owner's OneDrive files to copy them to the selected Google Drive folder.

Storage and sharing

Transfers pass through the owner's computer between the selected Microsoft and Google services. Authentication tokens and configuration are stored locally in the owner's private rclone configuration. File caches, transfer logs, file listings, and checksum records may also be stored locally. Files remain in the selected cloud accounts until the owner changes or deletes them.

This personal configuration does not sell user data, serve advertising, or send files to unrelated recipients. Data is shared only with the cloud services and destinations the owner directs rclone to use. Google and Microsoft process information under their respective policies.

Control and retention

The owner can stop rclone and revoke its access through their Google or Microsoft account settings. Revoking access does not itself delete existing cloud files or local caches. The owner controls those files and may remove them using the relevant cloud service or local filesystem tools.

This website

This static information site contains no sign-in, analytics scripts, or file uploads. It does not contain cloud files or authentication credentials. Its hosting provider may process ordinary web request information as part of serving the site.

Limited use

Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Questions about this configuration can be directed to the repository owner through their GitHub profile.
